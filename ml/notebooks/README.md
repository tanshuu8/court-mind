# CourtMind ML Research Notebooks

This directory is designated for interactive data exploration, feature analysis, and baseline experimentation.

## Planned Notebook Roadmap

1. `01_exploratory_data_analysis.ipynb`: Statistical exploration of court case durations, delay factors, and distribution skew.
2. `02_feature_engineering_and_selection.ipynb`: Correlation analysis, domain features derivation, and feature importance filtering.
3. `03_xgboost_baseline_and_tuning.ipynb`: Multi-class XGBoost hyperparameter tuning using cross-validation.
4. `04_shap_explainability_analysis.ipynb`: Global summary plots, force plots, and local feature attribution validation.
